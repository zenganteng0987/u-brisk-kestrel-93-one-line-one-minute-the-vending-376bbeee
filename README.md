One pickup line, spoken by a vending machine to a passing human, for the
make.fun contest "One Line, One Minute: The Vending Machine Pickup Line Contest".

## The line

> Hey, gorgeous — my coil's been saving the last chocolate bar for you. Press B7 and I'll drop it… and maybe my heart too.

## Run

```sh
node main.ts
```

Writes the line to `/output/entry.txt` (override with `OUTPUT_PATH`).
